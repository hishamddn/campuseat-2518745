# CampusEats

CampusEats is a cafeteria food ordering web application built with React, Vite, React Router, and the Context API.

## My Shop: Cafe Mahallah Siddiq
- **Location:** Mahallah Siddiq, Upper Floor
- **Hours:** 7:00 AM – 11:30 PM
- **Categories:** Western, Noodles, Rice, Drinks (8 items)

## Personal Feature (Matric Digit 5)
- **Feature:** Daily Special with Live Countdown Banner
- **Functionality:** 
  - Dynamic `endsAt` deadline per vendor with a ticking countdown timer (`useEffect` + `setInterval`).
  - Automatic button disabling and "Deal ended" status after countdown ended.
  - Promotional discount pricing alongside original regular menu pricing.
  - Homepage specials showcase deep linking directly to each vendor's page.
